### Notes on the four `PARTIAL` requirement verdicts

All 35 requirements received a verdict; none is `NOT VERIFIABLE`. `R18`, `R31`, `R34`, and
`R35` are `PARTIAL` because each is fully specified for a durable, live deployment and this
release is deliberately neither. In every case the missing half is built but unwired
(`record_visitor_pick`, `record_analytics_event`, `purge_expired_identifiers`, the job
queue), and the product states the limitation on the page rather than implying the feature
works. `R33` is `CONFIRMED` because it is a gating requirement — public display has not
activated, which is exactly what it demands; the _contents_ of a future rights record could
not be inspected, and that is recorded in Part 5 as a gate-level limitation.
